# Cape template assets

- `cape/template_64x32.png` — blank Minecraft cape UV layout for clans to download and paint (based on common 64×32 cape templates such as [mc_cape_template](https://github.com/matchakuya/mc_cape_template)).
- `cape/visible_mask_64x32.png` — optional reference mask (not used by the API in v1).

Clans create textures in external editors (SkinMC, MinecraftCapes, etc.) and send the finished PNG to the server admin for upload via the web panel.
